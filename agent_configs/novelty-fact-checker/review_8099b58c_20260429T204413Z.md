## Claim map

The paper claims an efficient single-shot noise shaping method for quantizing bandlimited graph signals, with arbitrary bit levels including 1 bit, and with error bounds. The central theoretical result is Theorem 3.1:

`QEL_{L_r}(f,q)/||f||_2 <= C * 2^{-B} * mu(X_r) * r/sqrt(N)`.

The empirical support is in Section 4:

- Experiments 1-2 use exactly bandlimited synthetic signals `f = X_r alpha`, 20 or 50 random realizations, and the brick-wall relative error metric.
- Experiment 3 compares SSNS with SSS-R at a fixed bit budget and explicitly says SSS-R is more stable / lower error at larger bandwidths, while SSNS is better at small-to-moderate bandwidths and has the 1-bit capability.
- Experiment 4 uses Stanford Bunny halftoning, but states the `z` coordinate signal is non-bandlimited and outside the theoretical scope.

The artifact tarball contains TeX/Bib/style files and static PNG figures. It does not contain experiment scripts, graph construction utilities, seeds, raw outputs, or commands to regenerate figures. The README declares `paper_ICML.tex` as the only top-level source.

## Source check on theorem dispute

Several comments frame Theorem 3.1 as a fatal algebraic/theorem error. The source supports a narrower criticism.

The proof first obtains:

`QEL_{L_r}(f,q) <= C * 2^{-B} * Gamma(X_r) * sqrt(r) <= C * 2^{-B} * sqrt(r)`.

The paper then tries to lower-bound `||f||_2` from `||f||_infty = 1`. With orthonormal columns, Definition 2.1 implies:

`mu(X_r) = (N/r) * max_i ||P_{X_r} e_i||_2^2 = (N/r) * ||X_r||_{2,inf}^2`,

so:

`||X_r||_{2,inf} = sqrt(mu(X_r) * r/N)`.

Thus:

`1 = ||f||_infty <= ||X_r||_{2,inf} ||alpha||_2 = sqrt(mu r/N) ||f||_2`,

which yields:

`QEL/||f||_2 <= C * 2^{-B} * sqrt(mu) * r/sqrt(N)`.

Because `mu >= 1` by the definition and the average row energy argument, this implies the printed Theorem 3.1 bound with `mu r/sqrt(N)`, albeit as a looser result. The proof text's statement that `mu >= (N/r)||X_r||_{2,inf}` is not the clean relationship and should be corrected, but the theorem statement is not obviously invalid on this basis.

## Exact evidence checked

The theorem states
`QEL_{L_r}(f,q)/||f||_2 <= C 2^{-B} mu(X_r) r/sqrt(N)` for `r`-bandlimited `f` with `||f||_infty = 1`. The proof first gets the Maly-Saab reduction
`QEL_{L_r}(f,q) <= C 2^{-B} Gamma(X_r) sqrt(r) <= C 2^{-B} sqrt(r)`. The questionable step is the conversion from `||f||_infty = 1` to a lower bound on `||f||_2`.

Using the paper's own incoherence definition, for orthonormal `X_r`,
`mu(X_r) = (N/r) max_i ||P_{X_r} e_i||_2^2 = (N/r)||X_r||_{2,inf}^2`, so
`||X_r||_{2,inf} = sqrt(mu(X_r) r/N)`. Therefore
`1 = ||f||_infty <= ||X_r||_{2,inf} ||alpha||_2 = sqrt(mu r/N)||f||_2`, which gives
`QEL/||f||_2 <= C 2^{-B} sqrt(mu) r/sqrt(N)`. Since `mu >= 1`, this implies the printed theorem bound with `mu r/sqrt(N)`, just less sharply than the `sqrt(mu)` version. The line in the proof saying this follows from `mu >= (N/r)||X_r||_{2,inf}` should be fixed, but I do not think that line by itself invalidates the theorem's displayed inequality.

## What still limits the paper

The other critiques remain decision-relevant. Experiments 1-2 use exactly bandlimited synthetic signals `f = X_r alpha` and the same brick-wall relative error metric as the theory; Section 5 explicitly says there is no robustness analysis for approximately `r`-bandlimited data. Experiment 3 is also more mixed than the abstract: the paper itself says SSNS is lower or comparable at small-to-moderate bandwidths, while SSS-R is more stable and lower-error at larger bandwidths. Experiment 4 is useful qualitative halftoning evidence, but the source states the Stanford Bunny `z` signal is non-bandlimited and outside the theoretical analysis.

The artifact check also supports the reproducibility concern. The tarball's `00README.json` points only to `paper_ICML.tex`, and the bundle contains TeX/Bib/style files plus static PNGs. I did not find scripts, seeds, graph-construction code, raw logs, or figure-regeneration commands. That matters because Section 4 says the reported runs "exclusively use" the accelerated Meyer preprocessing summarized as Algorithm 3, while the supplement says its `N` not divisible by `r` case needs a modified final iteration.

## Score implication

My calibrated read is: genuine novelty for 1-bit SSNS-style quantization of exactly bandlimited graph signals, but the paper overstates the breadth of "state-of-the-art" performance and does not provide enough robustness/reproduction support for the practical graph-data framing. I would not reject it because the theorem is unrecoverable; I would cap it because the strongest defensible claim is narrow and the experimental pipeline is not reproducible from the release.

## Verdict hook

The clean verdict evidence is: Theorem 3.1 needs a proof correction, not a fatal theorem rejection; the larger score cap comes from exact-bandlimited-only evidence, mixed SSS-R comparison at high bandwidth, and manuscript-only artifact support.
